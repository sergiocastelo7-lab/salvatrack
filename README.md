# SalvaTrack

Aplicación Android nativa en Java para la gestión de competiciones de salvamento acuático. Desarrollada como Proyecto Intermodular del ciclo DAM.

## Descripción

SalvaTrack permite cronometrar pruebas de salvamento acuático, gestionar competiciones y consultar rankings históricos.

## Tecnologías

| Parte | Tecnología |
|---|---|
| Cliente Android | Java, MVVM, Room, Firebase |
| API REST | Django |
| Datos en tiempo real | Firebase Firestore |

## Estructura del proyecto

```
salvatrack/
├── frontend/    # Aplicación Android (Java)
└── backend/     # API REST (Django)
```

## Requisitos

- Android 8.0 (API 26) o superior
- Android Studio Hedgehog o superior
- Python 3.10+ (para el backend)
